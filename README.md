# 모른다고 답해 줘 · AI 질문 도우미

AI에게 논문이나 자료를 물어보는 학생·취업 준비생이, 질문에 한 문장을 덧붙여 AI가 없는 논문 내용을 지어내는 답을 덜 받도록 돕는 정적 웹 앱입니다.

- 공개 주소: https://few0579-a11y.github.io/ai-question-helper/
- 근거: 유지민 (2026). "모르면 모른다고 답하라"는 한 문장이 Claude의 가짜 논문 지어내기를 줄이는가. ALEPH 10번 과제 논문. 결과 수치는 `data.js`에 있습니다.

## 할 수 있는 일

1. **질문에 문장 붙이기**: 질문 끝에 "확실하지 않으면 모른다고 답해 주세요."를 붙이고 복사합니다. 논문을 묻는 질문이면 논문 결과에 따른 주의점을 보여 줍니다.
2. **효과와 한계 보기**: 문장 유무에 따른 결과(지어낸 답 7/20 → 1/20, 실제 논문 정답 20/20 유지 등)와 이 결과로 말할 수 없는 것 5가지를 보여 줍니다.
3. **받은 답 점검하기**: 두 질문에 답하면 논문의 판정 기준(지어냄 / 추측 섞인 보류 / 순수 보류)으로 분류하고 다음에 할 일을 안내합니다.

## 로컬에서 실행

설치할 것이 없습니다. `index.html`을 브라우저로 열거나, 이 폴더에서 `python -m http.server 8000` 실행 후 http://localhost:8000 을 엽니다.

## 데이터와 비밀값

- AI를 직접 부르지 않으므로 API 키나 환경 변수가 없습니다.
- 앱에 들어간 데이터는 논문의 집계 수치뿐이며 개인정보가 없습니다. 3번에 붙여 넣은 글은 브라우저 안에서만 쓰이고 어디에도 전송되지 않습니다.
